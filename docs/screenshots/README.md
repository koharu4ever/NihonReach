## 数据与权限边界

- 截图服务在本地开发 app 容器运行，使用独立临时 SQLite 数据库；开发和部署方案仍使用 MySQL，截图不作为 MySQL 集成测试结果。
- 产品和分类来自仓库 Seeder；额外询盘明确标为虚构数据，使用 `example.test` 邮箱，不含真实客户、手机号或生产凭据。
- 后台使用只存在于本地临时数据库的 Demo 管理员登录，不提供生产后台共享账号。
- 截图时只展示状态表单，不将静态图片当作保存成功、并发安全或完整验收的证明；业务行为以代码、测试和实际交互为准。
